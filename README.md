# Системний монітор 2.0.2 (C# / WPF)

Одна програма-віджет для Windows 10/11: CPU, GPU, VRAM, FPS, 1% low, frame time, RAM, ping, диск,
вентилятори, споживання, графіки, плеєр Spotify, радар звуку, статистика. Справжнє скло Windows,
GIF на фоні, гаряча клавіша «сховати/показати».

## Як отримати готовий .exe

### Спосіб 1. Зібрати на своєму ПК (один раз)
1. Встановіть **.NET 8 SDK**: https://dotnet.microsoft.com/download/dotnet/8.0 (кнопка «SDK», Windows x64).
2. Розпакуйте цю папку, наприклад в `C:\SystemMonitor-src`.
3. Двічі клікніть **`build.bat`**. Перший раз завантажаться пакети, це кілька хвилин.
4. Готовий файл: `publish\SystemMonitor.exe`. Це один самодостатній файл: .NET і Python ставити не треба.
   Його можна скопіювати куди завгодно й запускати.

### Спосіб 2. Без встановлення SDK (через GitHub)
1. Створіть безкоштовний репозиторій на github.com і завантажте в нього вміст цієї папки (разом з `.github`).
2. Відкрийте вкладку **Actions**, там пройде збірка `build`.
3. Усередині завершеного запуску, у розділі **Artifacts**, завантажте `SystemMonitor`: там буде `.exe`.

## Перший запуск
1. Двічі клікніть `SystemMonitor.exe`. На запит UAC (права адміністратора) натисніть **«Так»**.
   Права потрібні для температури процесора. Windows SmartScreen може попередити про невідомого видавця:
   «Докладніше» → «Все одно виконати».
2. Програма спитає, чи завантажити **PresentMon** (для FPS) і встановити драйвер **PawnIO** (для температури CPU).
   Натисніть «Так». Потім вона спитає про автозапуск з Windows.
3. Через 1–2 хвилини перевірте *права кнопка на панелі → Налаштування → Компоненти*. Якщо температура CPU
   досі «—», перезавантажте ПК один раз.

Усі файли програми (налаштування, журнал, завантажений PresentMon) лежать у `%AppData%\SystemMonitor`.

## Можливості
- **Liquid Glass у реальному часі.** Програма сама знімає екран позаду віджета, розмиває його, підсилює кольори і заломлює
  картинку біля країв, як товста скляна лінза (з легкою кольоровою дисперсією). Усе оновлюється до 60 разів на секунду,
  в тому числі під час перетягування. Налаштовуються розмиття, заломлення, дисперсія, насиченість, яскравість, частота кадрів.
  Є також підфарбування, блік, рамка, закруглення кутів, повільний «рідкий» блік, що пропливає по склу,
  і зміна кольору скла разом із температурою. Стилі: Liquid Glass, Темне скло, Неон, Сакура, Ліс, Суцільний.
  Якщо фон не змінюється, програма майже не навантажує процесор.
- **GIF або картинка на фоні** з повзунком прозорості (*Налаштування → Фон (GIF)*).
- **Плеєр Spotify** окремим віджетом: обкладинка, назва, виконавець, прогрес, ⏮ ⏯ ⏭. Працює через системне керування
  медіа Windows, тож підходить і для інших плеєрів. Перетягується окремо від панелі.
- **Радар звуку**: окремий віджет. Сектори показують гучність по каналах, стрілка показує загальний напрямок, а короткі
  сплески (кроки, постріли) з'являються на колі там, звідки почули звук, і згасають за секунду. Бас відфільтровується,
  щоб вибухи й музика не заглушали кроки. 5.1 і 7.1 дають напрямки спереду, ззаду, збоку; у стерео видно лише ліво/право.
  Підпис у куті радара показує, скільки каналів зараз приходить.
- **Гаряча клавіша** (за замовчуванням **F9**) ховає й повертає всі віджети. Змінюється у *Налаштування → Віджети*.
- **Статистика** (права кнопка → Статистика): макс. температури, час у іграх, середній FPS, найгірший 1% low, ping, трафік за день.
- Усі віджети перетягуються мишкою, позиції запам'ятовуються.

## Чесні обмеження
- Я писав цей проєкт без можливості зібрати й запустити його на Windows. Якщо збірка або запуск дасть помилку,
  скопіюйте текст помилки (або `%AppData%\SystemMonitor\log.txt`) і надішліть: це швидко виправляється.
- **Спосіб скла.** За замовчуванням «Авто» = Liquid Glass. Через те, що панель ховається від знімків екрана (інакше вона
  розмивала б сама себе), її не видно на скріншотах і в записі екрана. Для скріншота оберіть «Суцільний».
  Якщо Liquid Glass не запуститься (стара Windows), програма сама перейде на суцільний режим. У *Налаштування → Вигляд → Спосіб скла*
  є ще системні варіанти Acrylic.
- Краї закруглень можуть виглядати трохи зубчастими: Windows обрізає вікно без згладжування.
- **Радар звуку** не бачить тривимірного звуку з гри в навушниках: він читає лише канали, які Windows віддає на пристрій.
  Для напрямків «спереду/ззаду» поставте в Windows і в грі 5.1/7.1.
- **Заряд мишки** показується, лише якщо Windows отримує його по Bluetooth. Якщо ні, у рядку буде «—».
- У справжньому **повноекранному** режимі ігор віджети не видно. Використовуйте віконний режим без рамки.
- FPS береться з PresentMon. Деякі ігри з античітом можуть блокувати такий моніторинг.

## Видалення
Вимкніть автозапуск у налаштуваннях, закрийте програму (права кнопка → Вийти), видаліть `SystemMonitor.exe`
і папку `%AppData%\SystemMonitor`. Драйвер PawnIO знімається командою `winget uninstall namazso.PawnIO`.

## Своя іконка
Іконка вшивається в `SystemMonitor.exe` з файлу `icon.ico` у корені проєкту. Щоб поставити свою:
1. Перетворіть картинку (PNG) на `.ico` з розмірами 16, 32, 48, 256 (наприклад, на сайті icoconvert.com).
2. Замініть файл `icon.ico` у папці проєкту (ім'я має лишитися таким самим).
3. Зберіть програму заново (`build.bat` або GitHub Actions).
